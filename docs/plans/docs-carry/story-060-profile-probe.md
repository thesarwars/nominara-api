## S3, the structure-match gap (owner decision 99k)

Migration **0201** adds a nullable `geo_alignments.page_structure` jsonb (`{tables, lists: {ordered, unordered, definition}}`, zod `contracts/analytics/geo-page-structure.schema.ts`; NULL = never read for structure). The alignment session (`openAlignmentSession`) builds the STORY-050 document model from the HTML it **already fetched** and writes the summary with the live page, on both its insert and its write-onto-a-pending-row paths: no new fetch. `loadStructureInput` reads the **latest** summary per cluster (`DISTINCT ON (prompt_cluster_id)`, scoped to the project) into `StructureInput.clusterPages`; `buildStructure` judges each table-dominant, sufficient cluster against **its own page only** (never a union). A cluster with no page read, a NULL summary or one that does not parse is not assessed and asserts no gap. The `pages` field of the earlier shape is still accepted. The page for a cluster is its alignment target URL (as decision 99f states for 057). The subject inventory classes the column `omit` (derived counts); a draft does not rewrite it.

## Robots exemption for the Wikimedia APIs (owner decision 99j)

Wikimedia's robots.txt (`User-agent: *`, `Disallow: /w/`, an Allow only for `api.php?action=mobileview`) would refuse every probe request under decision 70(d). The probe's JSON fetcher therefore uses a gate of its own (`src/lib/geo/entity-probe/wikimedia-gate.ts`) with a **narrow exemption**: https, default port, host `www.wikidata.org` with path `/w/api.php` and `action` in `wbsearchentities`, `wbgetentities`; host `en.wikipedia.org`, path `/w/api.php`, `action=query`. Any other host, path, scheme, port or action on those domains (pages, `Special:`, `index.php`, `parse`, `edit`) still obeys robots.txt, and the exemption is re-judged on every redirect hop. The shared `crawlGatedFetch` has no exemption (`createCrawlGate({ robotsExempt, exemptCrawlDelaySeconds })` is the option). What stays: the SSRF guard, the identified `NominaraBot/1.0 (+https://nominara.com/bot)` User-Agent (Wikimedia API etiquette: identify with contact information), and a strict per-host rate of one request per second (the shared budget is 500 ms), serial and never a burst. Reference text to amend: decision 70(d) gets this one stated exception.

Not built, for the owner: the other five nodes (G2/Capterra, Crunchbase, LinkedIn, GitHub, category directory) and their access terms.
